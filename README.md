# 一天

用一天重整你的整个人生。一个纯静态、数据全本地的网页应用。

> 流程来自 Dan Koe《How to fix your entire life in 1 day》：早上挖出你真正在追求什么，白天从自动挡里出来几次，晚上把它收成一张能带走的卡片。

---

## 它是什么

- 31 个问题，分三幕：早晨（心理深挖）→ 白天（几次停顿）→ 晚上（整合成面板）
- 六个进度路标，只在跨过时出现，问的不是「你完成了吗」，而是「你到底有没有到达」
- 关卡式写作：一屏一题，自动保存，随时退出随时回来，一次 run 最多跨 7 天
- 最后生成一张 1080×1920 的面板图，可以存进相册、设成锁屏
- 历史按次存档，可以把历次的「敌人」并排看

## 它不是什么

- 不会提醒你。没有任何推送、没有站内弹窗、没有打卡
- 不会给你答案。不接 AI、不做总结、不做建议
- 不会上传任何东西。没有统计脚本，没有第三方字体，没有外链请求

数据只存在你这台设备的 `localStorage` 里。清理浏览器数据会清空它，所以请定期在「设置 → 导出备份」里存一份 JSON。

## 本地打开

纯静态，三个文件，零依赖零构建。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用，但用本地服务器更稳妥。

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "一天"
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

然后：仓库 → Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`，目录 `/ (root)` → Save。

等一分钟，地址是 `https://<你的用户名>.github.io/<仓库名>/`。

**手机上用**：Safari 打开后点分享 → 添加到主屏幕。它会像一个 App 一样全屏运行，离线也能用（页面本身已缓存）。

## 让系统替你提醒（可选）

网页本身不会推送，但手机的「快捷指令」可以每天定时把它打开：

**iPhone**：快捷指令 → 自动化 → 新建个人自动化 → 特定时间 → 每天 11:00 → 打开 URL → 填 `https://<你的地址>/#/today` → 关闭「运行前询问」

**安卓**：MacroDroid 或 Tasker，同样动作。

提醒由系统发，网页只负责被打开。设置页里有「复制地址」按钮。

## 文件

```
index.html            骨架
style.css             设计系统（一天的光线：背景随时段变化）
questions.js          题库 + 权重 + 六个检查点，改文案只动这里
app.js                状态、路由、渲染、存图
manifest.webmanifest  添加到主屏幕
DESIGN.md             设计大纲：流程、权重、判定逻辑、数据模型
OPEN.md               还没定的取舍
```

## 已知取舍

- **不做提醒**：技术边界决定了网页在关闭后无法推送，与其做一个不可靠的提醒，不如把「打开时接住你」做好。
- **不做游戏化**：没有徽章、没有连续天数、没有庆祝动画。只有一条 2px 的进度线。
- **进度按价值加权**，不按题数平均：反愿景 26%，白天的停顿 19%，规则只有 8%。
- **白天留下 3 条就算完成**：写 6 条当然更好，但不设门槛，因为设了门槛就会有人为了凑数而写。
