# 一天

用一天重整你的整个人生。一个纯静态、数据全本地的网页应用。

> 流程来自 Dan Koe《How to fix your entire life in 1 day》：早上挖出你真正在追求什么，白天从自动挡里出来几次，晚上把它收成一张能带走的卡片。

线上地址：<https://fancymf.github.io/changeLife/>

---

## 它是什么

流程只有三幕，中途不打断：

1. **早晨 · 心理深挖** — 14 题，一屏一题，自动保存
2. **白天 · 随机记录** — 想到就写一句，可以从题库挑问题，也可以自由记录；不设提醒，不设完成门槛
3. **晚上 · 整合** — 8 题，答完自动进入结算页

结算页是**这一天全部问题与回答的汇总**（不只是晚上），另加六张可编辑的面板卡。点「保存图片」生成 1080×1920 的卡片，可存进相册、设成锁屏。点「结束这一天」后归档进历史。

历史按 `YYYY.MM.DD` 存档，点开就能看到每个问题的问题原文和你的回答（白天碎片会带上当时挑的问题）。

## 它不是什么

- 不会提醒你。没有任何推送、没有站内定时弹窗、没有打卡
- 不会给你答案。不接 AI、不做总结、不做建议
- 不会上传任何东西。没有统计脚本，没有第三方字体，没有外链请求

数据只存在你这台设备的 `localStorage` 里。清理浏览器数据、用无痕模式都会让它消失，所以请定期在「设置 → 导出备份」里存一份 JSON。

## 导出：用什么格式

结算页和历史详情页都能导出单次记录；历史页底部可以「导出全部」。

| 按钮 | 文件 | 适合 |
|---|---|---|
| **Markdown（推荐）** | `一天-2026.11.04.md` | 长期归档。纯文本 UTF-8，手机和电脑都能读、能编辑，能直接贴进 GitHub / Notion / 备忘录，能 diff，十年后还能打开 |
| 纯文本 TXT | `一天-2026.11.04.txt` | 微信、邮件里直接预览最稳。带 UTF-8 BOM + CRLF，Windows 记事本打开不乱码 |
| 阅读页 HTML | `一天-2026.11.04.html` | 排版最好。自包含单文件、不联网，手机和电脑用浏览器打开即读；顶部有「打印 / 存为 PDF」 |
| 复制全文 | 剪贴板 | 直接粘到别处，内容是 Markdown |
| 设置 → 导出备份 | `changeLife-backup-*.json` | 完整结构化数据，可以导入回来，用来换设备或做统计 |

**为什么主推 Markdown**：它本质就是纯文本，所以「TXT 能在的地方它也能在」，同时多了标题层级，31 组问答不会挤成一片；它又是 Git 友好的，和这个仓库天然配套。

**没做的两种**：

- **Excel / CSV** — 表格适合一题一行地检索，但每个回答是一段长文本，塞进单元格后在手机上要横屏放大，反而更难读；CSV 的中文编码和答案里的换行、逗号转义也容易出错。真要做跨次统计，用 JSON 备份更合适。
- **直接生成 PDF** — 纯前端零依赖生成中文 PDF 必须内嵌几 MB 字体，会破坏「十年后还能跑」的前提。改成让浏览器把 HTML 阅读页打印成 PDF，排版由 CSS 控制、字体用系统的，两端都成立。

三个导出文件都是纯文本，几 KB，微信 / AirDrop / 邮件随便传。

## 本地打开

纯静态，四个文件，零依赖零构建。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用，但用本地服务器更稳妥。

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "一天"
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

然后：仓库 → Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`，目录 `/ (root)` → Save。

等一分钟，地址是 `https://<你的用户名>.github.io/<仓库名>/`。

**手机上用**：Safari 打开后点分享 → 添加到主屏幕。它会像一个 App 一样全屏运行。

改完代码推送后手机可能有缓存，下拉刷新一次；还不行就把主屏图标删了重加。

## 让系统替你提醒（可选）

网页本身不会推送，但手机的「快捷指令」可以每天定时把它打开：

**iPhone**：快捷指令 → 自动化 → 新建个人自动化 → 特定时间 → 每天 11:00 → 打开 URL → 填 `https://<你的地址>/#/today` → 关闭「运行前询问」

**安卓**：MacroDroid 或 Tasker，同样动作。

提醒由系统发，网页只负责被打开。设置页里有「复制地址」按钮。

## 已知取舍

- **没有进度检查点**：曾在 10%/25%/50%/75%/90%/100% 放判定题，但它们大多不是原文的东西，且和「改变不是完成度」的立场冲突，已整体删除。
- **不做提醒**：技术边界决定了网页在关闭后无法推送，与其做一个不可靠的提醒，不如把「打开时接住你」做好。
- **不做游戏化**：没有徽章、没有连续天数、没有庆祝动画。只有一条 2px 的进度线。
- **进度按价值加权**，不按题数平均：反愿景 26%，白天的停顿 19%，规则只有 8%。
- **白天留下 3 条就算完成**：写 6 条当然更好，但不设门槛，因为设了门槛就会有人为了凑数而写。
